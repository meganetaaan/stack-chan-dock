# 保存録音の削除

versionCode 8から、録音画面の「保存した録音」に削除操作を追加します。録音名を示す確認画面で「削除」を押した時だけ、その録音を削除します。「キャンセル」、確認画面を閉じる操作、確認中のバックグラウンド移行では保持します。

## 操作と影響

1. 設定 → 「自分の声を録音」を開きます。
2. 保存した録音の「削除」を押します。
3. 表示された録音名を確認し、「削除」または「キャンセル」を押します。

**削除するのは録音だけです。** この録音から既に作成した声と、現在の声の選択は残ります。録音と話者状態は別のアプリ専用ディレクトリに保存され、既存の声を読み込む時に元録音を必要としません。話者状態の `recordingId` と元PCM hashは作成元の記録です。削除後も、同じ声の選択・読み上げ・起動後の復元ができます。

削除した録音は元に戻せません。その録音を元に声を作り直すには再録音が必要です。話者状態そのものの削除・共有・書き出しUIは今回追加しません。アプリデータ消去・アンインストールでは従来通り録音と声が消えます。

## 競合と保存の扱い

- 録音中、試聴中、保存中、声の変換・選択・追加モデル取り込み中、画面の切り替え中は削除できません。削除確認中は新しい録音・試聴・保存・声の変換を開始できません。
- 確認対象は名前ではなく、その録音のUUIDとメタデータのスナップショットです。同名の別録音には触れません。未保存の録音がある場合も、削除対象の保存録音だけを削除し、未保存の候補は保持します。
- 確認後の削除処理中は新しい操作を受け付けません。バックグラウンド移行で確定前に中断した場合は保持します。削除が既に確定していた場合は、再度一覧に現れません。
- アプリ内の録音ディレクトリだけを対象とし、UUID、実パスの親、既存メタデータを確認します。フォルダを同じ親の `.deleted-<UUID>` へ原子的に移す時点を削除の確定とし、所有する `audio.wav` と `recording.json` だけを消します。話者状態ディレクトリや選択ポインタは変更しません。
- 削除確定後のプロセス終了やファイル消去の失敗に備え、次回の一覧読み込みでも確定済みフォルダの後片付けを再試行します。消去しきれなかった場合はその旨を表示します。未知のファイル、ディレクトリ、外部へ解決されるパスは削除しません。

## 検証

すべて人工PCMと一時ディレクトリで検証します。確認前・キャンセル・確定前の中断での保持、録音名のスナップショット、同名録音の選別、二重確認、録音/試聴/変換中の拒否、未保存候補の保持、通常削除後の一覧復帰、確定直後の終了を模した再起動後の片付け、不正パス拒否を確認します。

作成元録音を削除しても、話者状態の内容と選択が変わらないこと、female03から既存の声へ選び直せること、再ロード後の復元ができることも検証します。合成runtime・エンコーダ・モデルは変更しません。

Android実機での確認ダイアログ、削除時のOS/ストレージ挙動、権限・背景移行、実際の声質、実Dock USBは未検証です。実際のユーザー録音の削除・取得、録音の外部送信、NucBoxマイク・GPU/Vulkan・COM操作は行っていません。
