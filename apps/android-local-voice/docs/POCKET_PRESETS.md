# Pocket日本語の標準10音声

標準のfemale03を既定のまま残し、配布元の女性5音声・男性5音声を選択できます。追加9音声のWAVや話者状態はAPK・配布ZIPに同梱しません。ユーザーが「公式音声を準備」を押し、取得先と非商用評価の説明を確認した場合にだけ、端末から公式配布元へ匿名で取得します。録音・話者状態を送信する経路はありません。

## 操作

1. 同じapplication ID・署名のversionCode 9を上書き更新します。既存モデルZIPと声を作る追加モデルZIPは同じものを使えます。
2. 設定でPocketを選び、既存Pocketモデルを検証・読み込みします。
3. 未導入なら pocket-tts-ja-reference-encoder-v1.zip を取り込みます。合成モデルやエンコーダを音声ごとに複製することはありません。
4. 「公式音声を準備（1/10）」から取得内容を確認し「公式から取得して準備」を押します。9音声合計約6MBを一つずつ取得・検証し、先頭最大5秒から端末内の話者状態を作ります。既存のfemale03は再取得・再変換しません。
5. 一覧から声を選び「この声を使う」または「選んで試聴」を押します。**試聴はその声を選択してから端末スピーカーで再生**し、その後の会話・読み上げも同じ声です。試聴はマイク・LLM・USBを使いません。

準備の完了だけでは選択を変えません。途中まで成功した声は中止・失敗後も使え、再試行は未準備・壊れた声だけを取得します。準備済みの声を使う際はネットワークやエンコーダは不要です。female03以外の「準備を解除」は名前を確認してその標準音声の状態だけを削除し、使用中ならfemale03へ戻します。録音や録音から作った声は削除しません。

## モデル互換性・既存の声

合成モデル、エンコーダ、日本語BOS、1000フレームの合成状態形式は既存のままです。追加の声は既存エンコーダとFlowLMの空状態へのprefillで作った、最大64フレームのコンパクトな参照状態です。5秒で1音声あたり約3.15MBのキャッシュです。5秒への切り出しは元の参照音声全体と同じ品質を保証しません。

従来のfemale03のWAV・事前状態・既定設定・旧モデルZIPは変更しません。英語公式プリセットや別モデルのKV状態は流用しません。声のメタデータには元参照SHA・revision・モデル/encoder/BOS fingerprint・状態hashを記録し、破損・切り詰め・別モデルの状態は読み込みません。

追加状態はfiles/pocket-presets-v1/ID/、本人の声は従来のfiles/pocket-voices/UUID/に分けます。選択ポインタの既存female03/UUID表現を維持し、新しい標準音声だけpreset:IDを使います。既存の録音から作成した状態・選択を移行せず読み込めます。起動時に選択した状態が失われていればfemale03に戻し、勝手な再取得・再変換はしません。アプリデータ消去・アンインストールでは状態も消えます。

## 中止・競合・検証範囲

準備・声切替・試聴・準備解除・本人の声の変換は同じ直列操作を使います。busyは同期的にUI状態へ反映し、連打、録音/再生/削除確認中、会話、モデル切替、別試聴との競合を拒否します。中止・画面離脱・バックグラウンド・音声フォーカス喪失でHTTP接続・変換・再生を止め、自動再開しません。取消は確定前の選択を保ちます。選択が確定した後の試聴中止・失敗では、表示どおり選択済みの声を保持します。

テストはTempの人工PCM・fakeの取得/エンコーダ/音声出力で実施します。全10選択・試聴の経路、旧UUID/female03互換、hash/サイズ/転送拒否、先頭5秒、キャンセル、部分成功後の再試行、読込失敗、復元、破損、準備解除、録音から作った声の保持を対象にします。実ユーザーの録音を読みません。実機での公式取得、9音声の実エンコード、声質・読み・メモリピーク・速度・画面・OS動作は未検証です。CPU1の既存runtimeを使い、新しいSDK・モデル・GPU経路は追加しません。

PCでは公式の実WAV9個も匿名取得し、固定サイズ・SHA-256を検証したうえで既存モデル/encoderをCPU1・低優先度で実行しました。全9音声の先頭5秒から64フレームの状態を作成・保存・再読込でき、全10選択のPCMが互いに異なり、同じ声の再実行とfemale03への復帰がそれぞれバイト一致しました。これは冒頭12フレームの計算結果で、人の聴感や文章全体の読み品質を示しません。WAVはRAMだけ、派生状態は所有確認したTempだけで扱い、終了時に削除しました。

検証記録のencode_wall_ms_pc_onlyはruntime.encodeVoice呼び出しの前後の壁時計時間です。通信・ファイルI/O・音声合成・再生を含まず、Androidの速度やRAMピークの測定ではありません。
