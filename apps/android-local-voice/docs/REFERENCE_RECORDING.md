# 自分の声を録音する

設定の声の項目から「自分の声を録音」を開きます。短い日本語の台本を読み、開始・停止・試聴・録り直し・名前を付けて保存できます。台本の目安は10〜20秒、録音上限は60秒です。保存した録音をPocketの読み上げに使う手順は [参照音声の作成と選択](POCKET_REFERENCE_VOICES.md) を参照してください。録音を保存しただけでは、使用中の声を変更しません。

## 操作

1. 設定 → 声 → 「自分の声を録音」を開きます。会話中の場合は会話を停止してから切り替えます。
2. 初回はマイクを許可します。許可だけでは録音を始めません。もう一度「録音を開始」を押します。拒否後に許可画面が出ない場合は「端末の設定を開く」からマイクを許可できます。
3. 静かな場所で台本を自然な速さで読み、「録音を停止」を押します。
4. 「試聴」で確認し、必要なら「録り直す」を押します。録り直しでは前の未保存音声を破棄します。
5. 40文字以内の名前を付けて「名前を付けて保存」を押します。保存した録音は下の一覧から試聴できます。

1秒未満の録音は保存候補になりません。画面を離れる操作では未保存録音の破棄を確認します。バックグラウンド移行・音声フォーカス喪失では直ちに停止し、未保存録音を破棄します。自動再開しません。保存済みの録音は残ります。保存録音は名前の確認後に [削除](RECORDING_DELETION.md) できます。作成済みの声は保持します。共有・書き出し操作はありません。アプリのデータ消去・アンインストールでは録音も声も消去されます。

## 音声と保存形式

- 既存の `AndroidMicrophoneSource` / `AndroidPcmAudioSink` を利用します。録音画面用のAudioRecordは24,000 Hz・モノラル・PCM16です。AudioRecordのクライアント形式が要求したレートと一致することを確認します。物理ADCのネイティブレートを測定するものではありません。
- 端末が `PROPERTY_SUPPORT_AUDIO_SOURCE_UNPROCESSED` を報告する場合は `UNPROCESSED`、それ以外は `VOICE_RECOGNITION` を使います。機種・音声経路による実際の音質、前処理、24kHz対応は実機確認が必要です。
- 保存前の録音は最大60秒のRAM上のPCMです。一時WAVの自動保存はありません。録音・試聴の終了時にAudioRecord/AudioTrackを解放します。
- 保存ボタンを押した時だけ、アプリ専用領域 `files/reference-recordings/<UUID>/` に `audio.wav` と `recording.json` を作ります。名前は表示用で、ファイルパスには使いません。
- WAVは44バイトの標準ヘッダーを持つリトルエンディアンPCM16モノラルです。JSONには名前、サンプルレート、サンプル数、時間ms、台本、作成日時、チャンネル数、ビット数、スキーマを保存します。
- 同じ親ディレクトリのステージへ書いてからディレクトリを原子的に移動します。通常の失敗・キャンセルはステージを片付け、既存の保存録音を保護します。保存中にプロセスが強制終了すると未完ステージが残る可能性があり、一覧では扱いません。
- 録音データをネットワーク・TTS・LLM・USBへ渡す処理はありません。既存のバックアップ除外設定を継続します。

## 競合と中断

録音画面を開く前に既存の試聴と会話の終了を待ちます。開いている間は会話開始、遠隔開始、モード変更、モデル変更を禁止します。USB接続の有無で録音を自動開始しません。録音中の停止は入力収集だけを取り消し、停止までのPCMを候補にします。画面離脱・中断は古いジョブの終了を待って候補を破棄します。世代番号で古いジョブの結果の混入を防ぎます。

## 検証

人工PCMと偽の音声入出力で、保存前にファイルを作らないこと、WAV/JSONの内容、名前とパスの分離、1秒未満・60秒超の制限、二重操作、開始準備中の停止、権限拒否、中断後の再録音、試聴停止と破棄、保存済み一覧の復帰、会話との排他を検証します。既存の会話・5エンジン・USB PC mockのテストも実行します。

Compose Previewに `RecordingScriptPreview`（344dp、文字1.5倍）と `RecordingSavePreview`（360dp）を追加しています。Previewはコンパイル確認のみです。Androidでの描画、実マイク・スピーカー、権限ダイアログ、実OSのフォーカス/着信/背景移行、実Dock USBは今回未検証です。NucBoxのマイク、GPU/Vulkan、COM12を操作していません。
