# 追加モデルZIPを選ぶ時の案内改善

ユーザー報告の表示は `Unexpected Pocket ZIP entry META-INF/com/android/build/gradle/app-metadata.properties` でした。このエントリは配布したAndroid APKの先頭にあります。追加モデル取り込みへAPKを渡すと同じエラーを再現できました。

本人限定Driveから追加モデルZIPを新たに全体読み戻しし、18,012,371 bytes、SHA-256 `3d09fd90ee09a538980fd9164470a3108dab3fbef7e57ddb3e9b0f4496a6e860` の一致を確認しました。ZIPの中身は `mimi_encoder.onnx`、`bos-before-voice.f32`、`manifest.json` の3個です。圧縮方式は通常のDeflateで、展開後の各サイズ・hashと、配布APKに埋め込んだ信頼マニフェストが一致します。短いreadとseek不可のストリームでも、実際の取り込み処理が成功します。

追加モデルZIPと既存モデルは変更しません。versionCode 7では次の案内だけを改善します。

- ファイル選択でZIP・ZIP圧縮ファイル・汎用バイナリに絞り、全ファイル許可を外します。表示名やMIME型を検証根拠にはせず、最終的にはZIP内容を検証します。
- 録音画面に選ぶファイル名 `pocket-tts-ja-reference-encoder-v1.zip` と「解凍せずZIPのまま」を表示します。
- APK内部のエントリが現れた時は、APKが渡されていることと選び直すZIP名を日本語で案内し、取り込みを拒否します。
- hash・展開サイズ上限・許可エントリ・重複/不足/未知エントリ拒否・キャンセル・既存インストール保護は維持します。APKのメタデータを無視して取り込む処理は追加しません。

## 操作

1. 新APKで上書き更新します。録音・作成済みの声・選択は保持されます。
2. 「自分の声を録音」→「声を作る追加モデルを取り込む」を開きます。
3. `pocket-tts-ja-reference-encoder-v1.zip`（約18MB）を選びます。ZIPを解凍する必要はありません。
4. 準備後、保存録音から声を作り、完了後「この声を使う」で切り替えます。

## 検証の範囲

PC CPU1でDriveの実ZIPと配布APKを使用して、正常ZIPの取り込み、元のエラー再現、新しい説明文、seek不可・短いread、ストリームの解放、失敗時の既存モデル保持と一時ディレクトリの除去を確認します。JVM回帰ではAPKの代表的な内部エントリ、誤ったhash、既存の拒否条件も確認します。

実AndroidのSAFプロバイダ・ファイル選択画面での操作、端末での新しい表示、参照音声の音質・メモリ・動作は未検証です。GPU、COM、NucBoxマイク、ユーザーの録音の外部送信は使用していません。
