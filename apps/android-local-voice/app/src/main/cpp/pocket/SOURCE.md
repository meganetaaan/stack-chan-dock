# Accepted Pocket tokenizer native dependency

`libirte_pocket.so` is reused byte-for-byte from the accepted `dev.irte.voice` v0.4.1-pocket-ja build. SHA-256: `71acdf79fc81fe0d806eb9af1de9b198edf9830f2d9da6fab7a5a8352c13e1e4`. Its exported JNI class remains `dev.irte.voice.PocketTokenizer`; the Java/Kotlin source package deliberately retains that name.

`pocket-tokenizer.cpp` and `upstream-CMakeLists.txt` are the corresponding source/reference build recipe. The latter's paths are relative to the original evaluation layout. It builds Google SentencePiece `31646a467d2051eb904e0b45de3a73e91fe1c1e3` with Android NDK r30, ARM64/API28, static C++ linkage, hidden/excluded static-library symbols and 16KiB LOAD alignment. No native rebuild or numerical change is made for this port. Source: https://github.com/google/sentencepiece/tree/31646a467d2051eb904e0b45de3a73e91fe1c1e3 . SentencePiece and its third-party notices are included in `assets/pocket-notices`.

The separate `onnx-irodori-isolated.aar` is the same verified ORT 1.30.0 CPU package used by that accepted app. Its SHA-256 and all original/ported source pins are in `app/libs/pocket-source-manifest.json`. It uses Java/JNI `ai.onnxirodori`, `libonnxirodori.so`, `libonnxirodori4j_jni.so`, and renamed exported ORT entry points to avoid other engines' runtimes. Native executable sections and relocation indices are preserved by the original isolation process. This port verifies runtime ELF fingerprints after APK stripping, including all three new native libraries; existing native bytes must stay identical to the prior Dock APK.
